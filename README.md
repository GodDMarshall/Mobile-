# Mobile Games

Offline local-multiplayer arena games for phones and tablets. All audio and characters are original.

## Katana Arena

- [Design doc](katana-arena/game-design-doc.md)
- [Godot 4.3 prototype](katana-arena/prototype/) — Spike Courtyard duel with Ronin Kage and Akane. See its README for running and tests.
- [Crimson Katana](katana-arena/web-fighter/index.html) — MK4-style 1v1 web fighter with 8 samurai, tournaments and finishers. [Play](https://claude.ai/artifact/VZgdj2QoxozStBwXa3F4fV)
